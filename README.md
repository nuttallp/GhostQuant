# GhostQuant

AI trading platform concept. This repository currently contains a project description only; it does not contain an executable trading platform.

[![Repository security](https://github.com/nuttallp/GhostQuant/actions/workflows/repository-security.yml/badge.svg)](https://github.com/nuttallp/GhostQuant/actions/workflows/repository-security.yml)

## Maintenance and diagnostics

[Actions](https://github.com/nuttallp/GhostQuant/actions) shows repository checks; the [Security tab](https://github.com/nuttallp/GhostQuant/security) shows available alerts. A workflow badge reports checks, not application uptime. Include the commit, error code, and sanitized reproduction when reporting a failure.

See [CONTRIBUTING.md](CONTRIBUTING.md) for changes and [SECURITY.md](SECURITY.md) for private vulnerability reports.
